# Flutter Learning Project

Repository học tập và thực hành **tạo ứng dụng Flutter cơ bản**, chuẩn bị kiến thức và kỹ năng cho những ứng dụng nâng cao hơn.

## Mô tả

Đây là một repository chứa các ứng dụng Flutter đơn giản được sử dụng để:
- 🎓 Học tập các khái niệm cơ bản của Flutter
- 💪 Thực hành các tính năng và widget phổ biến
- 🚀 Xây dựng nền tảng vững chắc trước khi phát triển ứng dụng phức tạp

## Cấu trúc Branch

Mỗi branch trong repository được chia thành các loại ứng dụng khác nhau:

- `main` - Branch chính (mặc định)
- `roll_dice` - Ứng dụng tung xúc xắc (Tìm hiểu về Stateful/Stateless)
- `quiz` - Ứng dụng làm trắc nghiệm (Tìm hiểu về điều hướng thủ công, lifting up state)
- `expense_tracker` - Ứng dụng quản lí chi tiêu (CRUD với RandomAccessFile/ByteData, Chart, Theme, Responsiveness)
- `behind-scene` - Tìm hiểu sâu quy trình xử lý 3 cây, các callback của stateful widget, key,...

## Bắt Đầu

Để bắt đầu làm việc với project này:

1. **Clone repository:**
   ```bash
   git clone https://github.com/NTV-CKN/flutter.git
   cd flutter
   ```

2. **Chuyển sang branch cần học:**
   ```bash
   git checkout [branch-name]
   ```

3. **Cài đặt dependencies:**
   ```bash
   flutter pub get
   ```

4. **Chạy ứng dụng:**
   ```bash
   flutter run
   ```
